# NetAiOps Snapshot Learning Artifact

NetAiOps is a simulated full-stack AI-powered IT operations platform built as a 15-step teaching history for a junior engineer. Browse `snapshots/` in order; each folder contains a full copy of the codebase at that moment plus `NOTES.md` and `CHANGES.md`.

Start with `snapshots/00-walking-skeleton/NOTES.md`, then compare each snapshot folder with the previous one in VSCode using “Compare Selected”.
